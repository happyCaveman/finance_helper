# Finance Helper

워런 버핏, 레이 달리오, 피터 린치 등 전설적인 투자자들의 지식과 투자 철학을 바탕으로 대화해 볼 수 있는 AI 금융 도우미입니다. 각 대가의 관점으로 기업과 투자에 대한 질문을 탐색해 보세요.

## 주요 기능

- 투자 대가 선택 및 채팅 인터페이스
- 각 투자 철학에 기반한 AI 투자 질의응답
- 실시간 스트리밍 답변 제공
